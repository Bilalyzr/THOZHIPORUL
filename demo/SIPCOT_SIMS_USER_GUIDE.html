1. System Overview

The SIPCOT Smart Industrial Monitoring System (SIMS) is a data-driven Industrial Operating System designed to transform Tamil Nadu's industrial governance. It provides real-time monitoring, compliance tracking, and analytics for industrial parks across the state.

Three User Roles

Admin

Full system control, user management, compliance oversight, park management, and system configuration.

Government Officer

State-wide monitoring, command center, compliance engine access, analytics dashboards, and report generation.

Industry User

Personal workspace, data submission, compliance score tracking, document management, and service requests.

Public Visitor

Home page, industrial parks overview, about page, features, and contact support - no login required.

2. Getting Started

How to Access the Portal

1

Open the Application

Navigate to the home page URL in your browser. The public landing page will load showing Tamil Nadu's industrial pulse data.

2

Click "Portal Login"

In the top navigation bar, click the "Portal Login" button. This takes you to the Role Selection page.

3

Select Your Role

Choose from three portals: Admin Portal, Industry Portal, or Government Portal. Each has a distinct color and icon.

4

Enter Credentials & Sign In

Enter your email and password. The system validates your role matches the selected portal. On success, you're redirected to your role-specific dashboard.

Tip: Use the "Forgot Password?" link if you need to reset your credentials. The system will send instructions to your registered email.

Admin Dashboard

/admin-dashboard

The main landing page after admin login. Shows:

  • 4 KPI Cards: Total Industries, Total Investment, Employment, Power Usage
  • Industry Growth Chart: Line chart showing 5-year growth (2021-2025)
  • Resource Consumption: Bar chart comparing resource usage by park

Command Center

/command-center

High-level state-wide monitoring dashboard:

  • 5 KPI Cards: Total CapEx (Rs. 24,500 Cr), Revenue, Direct Jobs, Indirect Jobs, Red Flags - each with growth percentage and trend indicators
  • District Investment Chart: Horizontal bar chart showing investment distribution across 5 districts
  • Park Rankings Table: Sortable table ranking parks by infrastructure score, industries, or investment. Top 3 parks highlighted in blue
  • Alerts Panel: Color-coded alerts (critical=red, high=orange, medium=yellow, low=blue) with action counts
  • 5-Year Growth Trend: Toggle between Investment and Employment trend lines
  • Activity Feed: Real-time log of system events (submissions, violations, registrations)

Services Tracker

/services

Kanban-style lifecycle tracker for NOCs, allotments, and service requests:

  • Summary Cards: Applied, In Review, Pending Approval, Completed counts
  • View Toggle: Switch between Kanban board and Table view
  • Kanban Columns: Applied > Doc Review > Inspection > Pending Approval > Approved > Completed
  • Click any card: Opens detail dialog with milestone timeline (stepper), bottleneck alerts, and action buttons
  • Update Status button: Admin/Govt can update service request status with confirmation

User Management

/user-management

Full CRUD for system users:

  • User Table: Name, Email, Role (color-coded chip), Status, Actions
  • "+ Add User" button: Opens dialog to create new user with name, email, role, status fields
  • Edit (pencil icon): Opens pre-filled edit dialog
  • Approve (check icon): Activates pending users
  • Delete (trash icon): Removes user with confirmation

Compliance Engine

/compliance-engine

Automated compliance monitoring and analytics:

  • Overview Cards: Compliant (892), Warning (156), Violations (45), Missing Data (67)
  • Three Tabs: Violations | Trends & Analytics | Predictions
  • Violations Tab: Filterable table with Severity/Status dropdowns. Each row has "Acknowledge" and "Escalate" buttons that update status with confirmation
  • Missing Submissions Alert: Shows count + deadline. "Send Bulk Reminder" sends email notifications. "Export List" downloads CSV file
  • Trends Tab: 9-month compliance score line chart
  • Predictions Tab: Table showing current vs. projected (1yr) for Investment, Employment, Compliance Rate, Active Industries. "Download Full Report" exports CSV

Report Center

/report-center

Self-service report generation:

  • Step 1 - Report Type: Select Investment Summary, Employment, Compliance, Park Performance, Resource Utilization, or Custom Query
  • Step 2 - Filters: Park, Period, Quarter, Industry Type dropdowns
  • Step 3 (Custom only) - Columns: Checkbox selection of which data columns to include
  • Step 4 - Format: PDF (branded), Excel (.xlsx), or CSV (raw)
  • "Preview Data" button: Shows first 5 rows in a table
  • "Generate Report" button: Creates and downloads the report file
  • "Save Configuration" button: Saves current filters to localStorage for reuse
  • "My Saved Reports" button: Opens dialog to load previously saved configurations
  • Recent Reports Table: Previously generated reports with download buttons

Settings

/settings

System configuration:

  • Security Section: Toggle 2FA, password policy, IP restriction switches
  • Data Backup: Toggle auto-backup, set frequency, trigger manual backup
  • System Info Sidebar: Version, uptime, last backup, database status

9. Frequently Asked Questions

Q: I logged in but see a different dashboard than expected?

A: Make sure you selected the correct portal on the Role Selection page. If you're an Industry user but selected the Admin portal, the system will show an "Access Denied" error. Go back to /role-selection and choose the correct portal.

Q: How do I submit quarterly data?

A: Login as Industry user > Click "Submit Data" in sidebar > Select period > Fill in all 5 steps > Click "Submit Data" on the Review page. You can also save as draft and continue later.

Q: Can I download my submission data?

A: Yes, go to Report Center > Select the report type > Choose your period and filters > Click "Generate Report" to download as PDF, Excel, or CSV.

Q: How do I know if I'm compliant?

A: As an Industry user, your Workspace shows a Compliance Health Score (0-100) with breakdown by category. Keep all scores above 80 for "Excellent" status.

Q: How do I apply for a new NOC or service?

A: Go to Service Requests > Click "+ New Request" > Select service type, priority, add description > Submit. You'll receive a reference number and can track progress on the Kanban board.

Q: The data shown is mock/sample data. Will it change?

A: Yes, the current system uses mock data for demonstration. Once the PostgreSQL database is connected and migrated (using schema.sql + schema_v2.sql), all data will be live from the database.

Q: How to print this guide as PDF?

A: Open this HTML file in any browser, then use Ctrl+P (or Cmd+P on Mac) and select "Save as PDF" as the destination.
